# IntelliSentiment – Explainable NLP-Based Movie Review Sentiment Analysis

IntelliSentiment is an NLP-based movie review sentiment analysis system that classifies reviews as **positive or negative** and provides an interpretable view of the factors influencing the prediction.

The project combines traditional NLP techniques, machine learning, and an interactive interface to make sentiment classification easier to understand rather than treating the model as a complete black box.

## 🚀 Features

- 🎬 Movie review sentiment classification
- 🧠 NLP-based text preprocessing and feature extraction
- 📊 TF-IDF-based text representation
- 🤖 Machine learning-based sentiment prediction
- 🔍 Explainability through feature importance
- 🖥️ Interactive Streamlit web application
- 📈 Model and prediction analysis through notebooks
